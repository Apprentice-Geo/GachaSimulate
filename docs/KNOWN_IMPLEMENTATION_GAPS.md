# Known Implementation Gaps

本文档记录当前实现尚未满足、但现有架构和专项文档已经确定的目标契约。处理这些项目时应修正实现，不要为了匹配当前代码而削弱对应文档；完成并验证后删除相应条目。

## 1. 架构信任边界和资源上限尚未全部落实

`ARCHITECTURE.md` 描述的是目标边界，以下差距需要分别处理：

- core stdout JSONL 缺少明确的单条和总量上限；YAML 与 manifest 读取、解析也缺少明确的资源上限。
- Linux 当前只向直接子进程发送 `SIGTERM`，尚未实现与 Windows `/T` 等价的原生进程树终止。
- 取消、窗口或应用关闭、协议错误和原生进程异常退出的清理路径需要统一验证，确保终止受管原生进程并清理临时 IR。

每一项都应在对应信任边界实现校验或清理，并留下能覆盖该边界的最小行为测试。
