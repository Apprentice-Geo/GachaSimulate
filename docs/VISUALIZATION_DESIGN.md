# Visualization Design

图表预览、结果可视化和导出帧共用深色画布。CDF 占左侧主列，终止原因分布位于曲线下方。右栏突出显示 P50、MEAN 和 P95，方便对照曲线读数。工作台导航、原位编辑控件与导出对话框见 [Workbench Design](WORKBENCH_DESIGN.md)。

## Visualization 视觉语言

### 表面与颜色

画布使用紫黑底色和明亮文字。CDF 绘图区用细边框和四角标记勾勒，边框向内绘制，曲线没有光晕。各分区的标题前有一条短色条。

颜色按职责使用：

- 页头使用明亮主标题，标题前以珊瑚红竖条定位；元信息沿用中性文字色。
- 特殊色参考抽卡常见的灰、绿、蓝、紫、金、红，提高点缀与数据色的饱和度；颜色不为统计量或分区赋予品质等级，也不表达好坏。
- 金色用于 P50，明亮浅蓝用于 P95，重点读数、marker 与引导线保持对应。
- 明亮青色用于 CDF 主曲线，蓝色用于四角定位标记；曲线下方仅在观测数据范围内使用极淡色面，不延伸到未覆盖的横轴区间。
- 分布、关键指标、索引与路径标题的短色条分别使用蓝、金、紫、绿，建立稳定的位置参照。
- 主要文字、次要说明和弱提示使用不同文字层级；普通标识符使用次要文字色。
- 分位 marker 的颜色与视觉权重表达阅读层级，不表达好坏或风险。MIN、MAX 为中性端点；MEAN 使用紫色空心菱形区别于分位圆点。
- 终止原因使用独立分类色组，只表示原因之间的对应关系，不表达好坏。

共享颜色、字体和画布 token 由 [Visualization tokens](../src/visualize/styles/tokens.css) 管理，统一限定在 `.visualize-scope`。三个宿主加载同一 [Visualization 样式入口](../src/visualize/styles/index.css)，Preview 仅按可用空间缩小共享 CDF 设计坐标，不独立维护颜色、字体、刻度、marker 或 compact 样式。正式页面与导出复用 `VisualizeScene`，仅宿主适配和动画驱动不同。

Workbench 主题与组件规范见 [Workbench Design](WORKBENCH_DESIGN.md)；[Workbench 样式](../src/renderer/styles.css) 的 scope 在 `.visualize-scope` 边界停止匹配。[foundation](../src/styles/foundation.css) 加载共享字号，并提供字体资源、box-sizing、基础 reset 和控件字体继承。CSS import 的组件位置不提供隔离保证。Export HTML 的 body 直接建立 Visualization scope，导出宿主独立负责固定尺寸与无滚动约束，不从 React 子树反向读取变量。具体色值、间距和组件尺寸不在本文维护第二份清单。

### 字体与数值排版

图表预览、结果画面和导出使用相同的字体。中文使用思源黑体 Regular、Medium、Bold，数字与标识符使用 JetBrains Mono Regular、SemiBold，并关闭编程连字。标题、正文、刻度和标记引用工作台共用的[字号层级](../src/styles/typography.css)，大数字使用其中的 `value`、`reading` 和 `hero`。所有字号按固定倍率换算为画布坐标。

累计模拟次数、累计结果、统计读数和 CDF 横轴刻度显示完整整数，省略千位分隔符。单位使用思源黑体，字号和字重均低于旁边的数值。

## 结果画布

图表预览标题下方的预览内容区使用 Workbench 卡片表面，浅色主题为白色，深色主题跟随 Workbench surface；图表本身保持独立暗色。正式可视化画布外围保留静态黑底白色星空；星点使用固定坐标，以暗小点为主、少量亮点为辅，不闪烁、不视差、不随图表缩放。标题栏保持 Workbench 样式，结果画布内部使用素净紫黑背景，辅助网格仅保留在绘图区。外围星空不进入 PNG 或视频，不扩大导出尺寸或留白。

CDF 使用弱边框和四角定位标记，统计栏和达成路径使用顶部细线，避免重复的封闭矩形框。使用独立 surface 或向内覆盖，不改变内容测量、绘图区与刻度，不叠加内容透明度动画。P50、P95 使用实线概率刻线，其他 marker 保留虚线辅助，MEAN 保留空心菱形。预览不添加宿主外框，图表四角沿用卡牌包边的双线形态，外角较长，内角较短且较淡，预览、正式画面和导出共用同一套绘制。曲线下方的青色渐变向基线淡出，双线角标降低饱和度，使阶梯曲线成为绘图区内最清晰的连续轮廓。

在工作台打开编辑模式后，正式画面停在动画终态。可编辑的文字位置由宿主提供输入框，分布曲线和统计读数继续显示。导出与图表预览使用只读渲染。

标题、副标题、模拟目标、统计物品名称、单位和说明均按单行短文案设计。编辑框只接受单行输入，超出输入框宽度的文字可横向滚动查看。结果画面和导出素材会在各字段的可用宽度内显示省略号，图表横轴标题和预览摘要中的单位也遵循这一规则。请在完成编辑后检查画面，发现一行放不下时自行缩短文案。

图表顶部为题签与 marker 标签分别保留空间，二者不得重叠。MIN 标签优先放在端点右上方，MAX 标签优先放在端点左上方；标签按实际字体、基线和描边的完整边界约束在标题下方与图表内部，不以文字锚点或固定字符宽度估算代替边界检查。三个宿主共享相同的标签布局与字体就绪后的测量规则。

结果画布保持固定设计坐标，由 [canvas constants](../src/visualize/constants.ts) 维护画布尺寸，[scene layout](../src/visualize/view/scene_layout.ts) 将尺寸注入共享画面与导出宿主的 CSS 变量，并维护图表设计尺寸。Electron 按宿主可用区域等比缩小并双向居中，窗口变化时重新适配，不放大超过原始尺寸，不提供手动缩放。宿主间距以 [preview styles](../src/visualize/styles/preview.css) 为准。该规则不用于整个桌面工作空间。

CDF 和下方的达成路径分布占左列，右侧统计面板跨两行，上下边缘与左列对齐。页头与主体共用列边界。标题和元信息位于同一行，副标题与最后一行元信息贴齐下缘。

页头左侧的主标题前有珊瑚红竖条，高度随字号调整。副标题与主标题文字左对齐。右侧三条元信息各占一行，标签左对齐，值紧跟在该行的冒号后。内容超宽时，优先压缩可编辑的文案，保留累计次数和累计结果的数值。

统计栏先列 P50、MEAN、P95。每项的指标名与中文标签并排，下方显示大号数值。接着按 MIN、P5、P25、P75、MAX 排列索引，每行左侧为标签和说明，右侧为数值。统计含义在底部注释中解释。各行填满分配的高度，较长的数值缩小字号，单位小于数值。左列的路径条、图例与用户备注左对齐。

素材导出使用原始画布尺寸，不经过交互宿主缩放。图表读取共享布局实际分配的区域尺寸，导出不单独指定图表尺寸。展示适配不能改变导出画面的布局和数据表达。画面内不放置工作台操作栏；更换结果、重播与导出入口由 Workbench 侧栏提供。

## 数据表达与文案

CDF 曲线、坐标、marker 和统计指标组成同一套阅读层级。网格与坐标轴是辅助参照，不能压过曲线；marker 和统计分组的视觉变化应保持数值含义一致。

使用通用文案：“模拟结果分布”“累计占比”“结束时的 `<item name>`”“累计模拟次数”，并配合简短的分位说明。结果名称来自展示配置，避免将某一种统计物品固化为所有场景的文案。

展示单位只追加到累计结果和统计指标的展示值；CDF 坐标轴标题与刻度保持无单位。单位和名称的调整只改变展示，不改变统计数据。字段职责与数据来源见 [DisplayConfig](DISPLAY_CONFIG.md)。

## 动效与导出一致性

动效用于引导信息出现和建立阅读顺序，保持克制。按阶梯曲线的实际绘制长度确定首次跨过 50% 和 95% 的时间；对应标记、引导线与右栏最终读数同步淡入。一次跳跃跨过两个分位时，在较高分位处同时揭示；曲线起点已达到的分位从起笔时开始揭示。曲线下的淡色面在曲线绘制完成后淡入，不先于曲线展示完整形状。共享动画采用 linear、ease-out quadratic 和 ease-out cubic 三类缓动，由各时间段明确选择；具体时长与进度计算集中维护在动画实现中。

有独立内容动画的容器不得再对祖先 opacity 做动画。面板背景、边框和阴影使用与内容并列的 surface 层，避免父子透明度叠乘导致内容意外变暗。

交互展示和逐帧导出必须保持同一套视觉行为；静态 PNG 与视频完成后的画面一致，切换时不发生布局或动画跳变。帧范围、终态帧和导出入口约束见 [Architecture](../ARCHITECTURE.md#可视化与导出)。

## 维护与验证入口

修改共享画面时同步检查图表预览、正式可视化与导出结果，保持相同字体、数据表达和动画终态。设计数值以 token 和场景布局源码为权威，不维护第二份数值表。布局测试保护几何和适配，截图检查视觉层级，实际导出验证共享画面；命令与验证要求见 [Development Checks](DEVELOPMENT_CHECKS.md)。
