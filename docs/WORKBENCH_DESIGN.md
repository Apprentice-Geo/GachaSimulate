# Workbench Design

本文维护导航、模拟表单、配置仓库、结果编辑器外壳、载入引导、侧栏操作组及导出对话框的视觉和交互规范。结果预览、正式画面及导出帧遵循独立的 [Visualization Design](VISUALIZATION_DESIGN.md)。模块边界见 [Architecture](../ARCHITECTURE.md)，检查入口见 [Development Checks](DEVELOPMENT_CHECKS.md)。

## 视觉原则

项目以抽卡意象为起点，以卡片与面板组织任务和信息，以品质色点缀重点，通过明确的几何边界、网格对齐和排版层级建立秩序。工作台强调操作清晰，可视化强调数据表达与游戏感。

Workbench 以任务操作、清晰反馈和稳定空间分配为中心。背景、面板与文字由浅色或深色主题决定，通过中性表面差异和文字层级组织内容；亮色主题采用冷灰背景、白色面板与弱表面列表。特殊色以抽卡中的灰、绿、蓝、紫、金、红为来源，在明确的卡牌品质语境中按该顺序表达递增的稀有度与价值。工作台以常见的蓝、紫、金为主要特殊色：蓝色承载常用操作，紫色与金色集中于运行区的卡牌插画。侧栏从工作台导航标签开始，标签上方使用 Lucide 的 `PanelsTopLeft` 分区窗口图标，以中性文字色表达工作区，不设置独立品牌标识；页头与分隔线保持中性。不按页面、操作或统计物品赋予品质等级，不为凑齐六色增加装饰。模拟工作流保留完整卡牌插画与局部动效：三张卡片从左到右按蓝、紫、金的游戏品质顺序排列，绕重合的底边中点旋转展开，右侧盖住中间、中间盖住左侧；入场动效沿用同一底边中点，保持三张卡片的底边中点重合。各卡片的卡面、边框与星芒使用对应色系，卡面保留同色系明暗渐变，外围轨道使用低饱和灰蓝色单色，按工作台主题适配明暗；轨道上的金色正八面体在公转时绕左下至右上的空间斜轴缓慢自转，自转与公转使用不同周期；通过真实投影、可见面切换和随朝向变化的三角面明暗表达体积，继续复用金色、高光和暗面 token，沿用轨道穿过卡牌前后的遮挡关系。轨道前后段共享同一份立体姿态；待运行、终态、切页、窗口隐藏与减少动态效果时停止自转，恢复运行时从暂停姿态继续。进度和次数使用等宽数字。卡牌品质色与品牌装饰不承载任务状态含义，不替代成功、警告或错误语义；绿色和红色的状态用途与物品品质用途独立。

## 主题与单一信息源

[共享字号](../src/styles/typography.css) 是 Workbench 与 Visualization 字号层级的唯一来源；[Workbench tokens](../src/renderer/tokens.css) 维护主题颜色、共享 spacing、radius 和工作台排版角色映射；本文记录语义与不变量，不复制数值表。已有专用布局几何由对应布局源码维护，不另建文档数值表。组件使用语义 token，不硬编码主题色。

两种界面共用字体资源、字号层级、文字权重与几何排版原则。工作台侧重任务操作，可视化侧重数据阅读；其场景职责如下：

| 设计维度 | 共同规则 | 场景职责 |
| --- | --- | --- |
| 排版 | 中文使用思源黑体，数字与标识符使用 JetBrains Mono；按语义角色选择共享字号 | 工作台直接使用桌面字号，可视化按固定倍率换算到设计画布坐标 |
| 颜色 | 区分主要、次要与弱提示文字；品质色与任务状态色分开 | 工作台维护浅色与深色主题，可视化固定深色 |
| 形状 | 面板以直角、细边界与弱表面差异组织内容；装饰不改变内容几何 | 工作台控件保留圆角，可视化通过刻线、短色条与图表定位标记划分层次 |
| 布局 | 主要分区稳定、边界对齐、滚动区域明确 | 工作台随窗口分配内容空间，可视化保持固定画布并整体等比适配 |

工作台的题签与辅助标签使用 `caption`，次要元信息使用 `meta`，列表正文使用 `content`，卡片标题、普通摘要与导出任务摘要使用 `body`，分区标题与仓库概览数字使用 `heading`，页面标题与导出对话框标题使用 `title`。模拟流程 SVG 的状态、次数与百分比分别使用 `content`、`caption` 和 `title`，随 SVG 画面等比适配。样式通过 Workbench 角色映射引用共享层级，不再用 `desktop-unit` 推导字号，也不在页面新增独立像素字号；`font` 简写同样遵守此规则。单位相对所属数值缩小，沿用相对字号，不建立新的基础档位。间距和控件几何继续由工作台布局 token 管理。可视化的读数层级、画布和导出约束见 [Visualization Design](VISUALIZATION_DESIGN.md)。

默认 Light，不跟随系统主题。侧栏底部的“设置”页提供浅色与深色选择，即时更新 Workbench 宿主的 `data-workbench-theme`，并通过桌面 renderer 的 localStorage 保存偏好；启动时在 React 渲染前恢复。非法或不可读的偏好回退到 Light；保存失败时仍切换当前主题，并显示无法保存的提示。两套主题提供相同名称的完整 token。颜色方案只作用于 Workbench，`.visualize-scope` 始终使用自己的暗色与原生控件方案。

设置入口固定在侧栏底部，与主导航和可视化操作组保持间隔，最小窗口下仍完整可见。设置页按“外观”和“软件信息”组织内容；软件名称、版本与许可证读取项目元数据，项目主页、问题反馈、许可证及第三方声明通过固定链接在默认浏览器打开。设置正文由 `.settings-body` 独立滚动，页头保持可见。

语义区分背景、面板、弱表面、普通和较强边界、主要和次要文字、主要操作及其前景、hover、selected、focus、链接、信息、成功、警告、错误、disabled、遮罩与阴影。卡牌品质与品牌使用独立的共享蓝紫金 token，不依赖操作或状态 token。数值和普通标识符沿用文字层级，不因是数据而使用强调色。蓝色用于主要操作、导航与列表选中、链接、焦点和信息状态；亮色主题的链接、焦点与信息状态沿用主要操作的蓝色，深色主题使用适合暗背景的明亮蓝色。成功、警告和错误独立表达，不与品牌或选中态混用。

[Workbench 样式](../src/renderer/styles.css) 在 Visualization 边界停止匹配。[foundation](../src/styles/foundation.css) 加载共享字号，并维护字体资源、box-sizing、reset 与控件字体继承。中文沿用思源黑体，数字使用 JetBrains Mono；标题使用正常字距。主题切换不改变字号、行高与几何。字体授权见 [Third-party notices](../THIRD_PARTY_NOTICES.md)。

## 组件与状态

按钮按主要、次要、弱操作和危险操作区分。主要按钮使用蓝色底色，危险操作使用错误语义。输入框与列表使用细边框；外围 Panel 与配置卡片使用轻微表面差异和直角，输入框与操作控件保留圆角，浮层使用克制阴影。圆角变化不改变控件几何尺寸。

hover 与 selected 明确区分；选中状态同时使用表面和边界表达。键盘 focus 清晰可见并绘制在边界内；组合搜索框只由外层显示焦点。disabled 使用专用表面和文字色，保留可辨认文字，不通过整体透明度降低所有内容。状态反馈同时提供文字和语义，不能只依赖颜色。

共享按钮和字段优先统一；图标通过 `WorkbenchIcon` 指定尺寸，滚动正文通过 `.workbench-scroll-region` 复用滚动条与边距样式；页面样式只承载实际职责差异。spacing 整理不改变已验收尺寸、换行、滚动所有者或空间分配。

配置仓库以状态色条和同色文字标签强化状态；统计物品以选中项内侧强调条标识当前选择，不额外加强已有边框或底色。强调条向容器内绘制，不移动文字或改变列表密度。

## 布局与空间行为

运行模拟、结果编辑和配置仓库页面填满可用空间。面板不能为减少留白而改为随内容收缩；内容数量变化时，主要分区应保持稳定。圆形模拟工作流填满控制区的剩余高度。

长内容在所属区域内滚动，滚动所有者必须明确；面板标题保留在内容滚动区域之外，避免用户滚动后失去分区上下文。

Electron 桌面不使用整体 `zoom` 填充大屏。Shell 的 Grid 分配 Sidebar 与 Main，页面通过纵向 Flex 让 Header 按内容占高、Workbench 填满剩余空间；结果编辑页另为保存状态与错误信息保留内容高度。Workbench 使用 `fr` 列比例和 `minmax(0, 1fr)` 行，参与收缩的 Grid/Flex item 显式设置最小尺寸。沿用共享 `border-box`，padding 与 border 均计入容器尺寸。页面不设置大屏最大宽度；Workbench 的字号、控件、图标、间距和侧边栏宽度保持固定，侧栏导航按钮为正方形，宽屏只增加内容空间。统计物品列表在宽屏改为双列，官方配置仓库列表在宽屏改为四列。图表预览按内容区可用宽度整体等比缩小；固定结果画布适配由 [Visualization Design](VISUALIZATION_DESIGN.md#结果画布) 维护。

深层组件不得以 `100vh - Npx` 推导父容器剩余高度。Breakpoint 仅用于必要的结构变化；当前桌面窗口最小规格为 1280×720，使用双栏布局，不维护低于该范围的 1100/820/620px 历史断点。若未来降低窗口下限，应一并设计结构变化并补充布局测试。

滚动所有者：

- 运行模拟：物品列表 `.simulation-item-panel`；控制区标题下的 `.simulation-control-body`。工作流使用等比居中的 SVG，保留可读的最小高度；高度不足时控制区正文滚动，操作、工作流与状态均可访问。工作流只保留外围圆形进度条与中央卡牌图标，不显示阶段节点、编号或节点标签；下方状态文字表达编译、模拟和保存阶段，外环只表达真实模拟次数进度；100% 后等待保存成功终态。待运行与终态停止循环动画，取消中明确显示反馈；切页或窗口隐藏时暂停装饰，返回时对齐真实进度。减少动态效果时保留阶段和进度，关闭装饰动画。
- 结果编辑：左侧可视化文案与右侧可视化预览均填满工作区高度。文案面板标题与三列摘要（结果指标 ID、累计模拟次数、累计次数）固定，`.result-editor-fields` 独立滚动六个单列字段；摘要标签为静态文本。`.result-cdf-chart` 填满标题下的剩余高度，图表作为独立子元素纵向排列，按扣除 padding 与滚动条后的实际可用宽度等比缩小且不放大；每个子元素按缩放后的高度占位，内容过高时由该区域纵向滚动，面板标题固定。预览复用正式图表的设计坐标、字体、刻度、标签布局与弱边框加四角定位标记，不另设 compact 样式或宿主灰框。标题下方的预览内容区使用与其他卡片一致的工作台表面（浅色为白色，深色跟随 Workbench surface），图表内部保留独立暗色，标题栏保持工作台样式；背景与导出边界见 Visualization Design。
- 配置仓库：页内切换官方仓库与本地目录，每次只显示一种来源。`.repository-list` 或 `.local-config-list` 在当前来源面板内滚动，分区标题与本地目录保持可见。
- 设置：`.settings-body` 承担外观与软件信息的正文滚动，页头保持可见。
- Main、Page 和 Workbench 不承担普通页面滚动，也不以裁切内容隐藏布局越界。可视化画布由独立宿主适配。

当前配置仓库规格：所选来源的列表面板独占页头、来源切换与概览栏下方的剩余空间。少量内容时仍保留面板高度，长列表在内容区域内滚动。重新进入页面默认显示官方仓库。

## 交互与状态反馈

模拟进度曲线的头端显示状态小圆，圆心始终跟随真实次数进度；中心灰点使用现有中性文字色，灰点与外环之间使用当前工作台面板表面色。小圆外环在待运行时为蓝色，编译、模拟与保存时为绿色，保存成功后为金色，取消与失败时为红色；完成态金色复用既有金色 token，作为此状态标记的专用约定。小圆外环只在运行动效启用时保留缺口并顺时针自转，前端清晰、向后沿圆弧逐渐淡出至透明，以尾迹表达方向；暂停、终态及减少动态效果时恢复完整、均匀实色的圆环。渐隐只改变透明度，继续复用已有状态色。

点击取消立即冻结进度曲线、头端小圆位置、百分比和次数，停止装饰动画，并显示取消中反馈。已排队或后续到达的阶段、进度和完成消息不能恢复进度或成功状态；本次临时结果即使已由 core 完整写出，也必须丢弃，不能替换已有结果及 sidecar。终止失败或等待退出超时仍保留取消决定，并提供重试取消入口，直到进程退出和清理结束。

结果编辑和结果可视化共享当前 GSR 会话，用户切换页面时继续围绕同一份结果工作。展示字段在失焦时保存；非法 sidecar 不被自动覆盖。保存、校验及失败信息应保持可辨认，具体持久化边界见 DisplayConfig 文档。

结果编辑和结果可视化未载入 GSR 时共用 Workbench 载入引导，使用 Workbench token 与面板样式。该状态不显示“结果展示信息”标题及其装饰，也不建立 Visualization scope 或渲染空的结果画布、CDF、统计量、达成路径和模拟元信息区域。选择 GSR 是唯一的主要操作；读取、取消和失败反馈留在同一载入面板。结果就绪后，结果可视化直接切换到正常 Visualization 画面，重放和导出只在此时出现。

结果编辑的文案字段从单行高度开始，随内容软换行增高，达到最大高度后在字段内部纵向滚动；加载内容、编辑内容和窗口缩放均应更新高度。软换行不写入换行符，用户显式输入的换行按原文保存。输入控件的焦点环绘制在边界内，组合搜索框只由外层显示焦点反馈；滚动内容与滚动条之间保留间距。

结果可视化导航项下方自动显示纵向操作组，仅当前页面且已有成功载入的共享结果时出现；在结果编辑页载入的结果同样有效。离开页面隐藏，再次进入恢复。操作组提供“更换结果”“重播动画”“导出素材”，显示期间始终可见，不新增展开步骤或第二列侧栏。主导航位置、尺寸和侧栏宽度保持稳定。

更换结果取消或失败时保留当前画面，反馈仍由页面承载；读取期间防止重复操作。播放动画时禁用重播；导出流程保持既有模态阻塞，关闭后焦点回到触发按钮。图内不再放置操作栏。

导出流程区分格式选择、覆盖确认、执行进度与终态。部分成功应说明已保存与失败的产物；取消确认后保持阻塞直到任务终态；残留资源清理受阻时保留重试和退出入口，不能通过关闭遮罩或切换页面绕过。模态标题与焦点行为属于交互验收内容。

## 维护与验证

保留四种窗口尺寸的布局契约及现有交互行为，新增侧栏操作组检查显隐、完整可见、键盘焦点、重播与导出流程。主题验证同时检查内嵌预览、正式可视化和导出画面不受影响。截图用于检查层级、密度、明暗衔接、裁切与遮挡；审美和使用感受由人工验收。不得为让检查通过而放宽无关布局断言。
