# Workbench Design

本文维护导航、模拟表单、配置仓库、图表预览与原位编辑、载入引导、侧栏操作组及导出对话框的视觉和交互规范。结果预览、正式画面及导出帧遵循独立的 [Visualization Design](VISUALIZATION_DESIGN.md)。模块边界见 [Architecture](../ARCHITECTURE.md)，检查入口见 [Development Checks](DEVELOPMENT_CHECKS.md)。

## 视觉原则

工作台用面板划分任务，页头、侧栏和分隔线使用中性色。浅色主题下，白色面板位于冷灰色背景上，列表用较浅的底色区分。侧栏顶部的 `PanelsTopLeft` 图标标识工作区。

蓝色标识主要操作、选中项和键盘焦点。卡牌插画用蓝、紫、金表现稀有度。运行状态始终配有文字，成功、警告和错误分别使用对应的状态色。

## 主题与单一信息源

工作台和结果画布共用[字号层级](../src/styles/typography.css)。组件通过 [Workbench tokens](../src/renderer/tokens.css) 引用工作台的颜色、间距、圆角和字号。

| 设计维度 | 共同规则 | 场景职责 |
| --- | --- | --- |
| 排版 | 中文使用思源黑体，数字与标识符使用 JetBrains Mono；按语义角色选择共享字号 | 工作台直接使用桌面字号，可视化按固定倍率换算到设计画布坐标 |
| 颜色 | 区分主要、次要与弱提示文字；品质色与任务状态色分开 | 工作台维护浅色与深色主题，可视化固定深色 |
| 形状 | 面板以直角、细边界与弱表面差异组织内容；装饰不改变内容几何 | 工作台控件保留圆角，可视化通过刻线、短色条与图表定位标记划分层次 |
| 布局 | 主要分区稳定、边界对齐、滚动区域明确 | 工作台随窗口分配内容空间，可视化保持固定画布并整体等比适配 |

题签与辅助信息使用 `meta`，列表正文使用 `content`，卡片标题和摘要使用 `body`，分区标题与仓库概览数字使用 `heading`，页面和对话框标题使用 `title`。模拟流程图中的状态、次数、百分比分别使用 `content`、`meta`、`title`，随 SVG 等比缩放。单位按所属数值的字号缩小。

默认浅色。侧栏底部的“设置”页提供浅色、深色和跟随系统三种选择。跟随系统时，工作台随系统明暗变化即时切换。应用主题时更新 Workbench 宿主的 `data-workbench-theme`，并通过桌面 renderer 的 localStorage 保存偏好；启动时在 React 渲染前恢复。非法或不可读的偏好回退到 Light；保存失败时仍切换当前主题，并显示无法保存的提示。两套主题提供相同名称的完整 token。颜色方案只作用于 Workbench，`.visualize-scope` 始终使用自己的暗色与原生控件方案。

设置入口固定在侧栏底部，与主导航和可视化操作组保持间隔，最小窗口下仍完整可见。设置页按“外观”和“软件信息”组织内容；软件名称、版本与许可证读取项目元数据，项目主页、问题反馈、许可证及第三方声明通过固定链接在默认浏览器打开。设置正文由 `.settings-body` 独立滚动，页头保持可见。

语义区分背景、面板、弱表面、普通和较强边界、主要和次要文字、主要操作及其前景、hover、selected、focus、链接、信息、成功、警告、错误、disabled、遮罩与阴影。卡牌品质与品牌使用独立的共享蓝紫金 token，不依赖操作或状态 token。数值和普通标识符沿用文字层级，不因是数据而使用强调色。蓝色用于主要操作、导航与列表选中、链接、焦点和信息状态；亮色主题的链接、焦点与信息状态沿用主要操作的蓝色，深色主题使用适合暗背景的明亮蓝色。成功、警告和错误独立表达，不与品牌或选中态混用。

[Workbench 样式](../src/renderer/styles.css) 在 Visualization 边界停止匹配。[foundation](../src/styles/foundation.css) 加载共享字号，并维护字体资源、box-sizing、reset 与控件字体继承。中文沿用思源黑体，数字使用 JetBrains Mono；标题使用正常字距。主题切换不改变字号、行高与几何。字体授权见 [Third-party notices](../THIRD_PARTY_NOTICES.md)。

## 组件与状态

主要按钮使用蓝底和对应的前景色。行内操作使用透明底，进入结果画面的按钮使用主题链接色，辅助操作使用次要文字色。危险操作使用错误色。面板和配置卡片为直角，输入框和按钮使用圆角，浮层用阴影与背景区分。

hover 与 selected 明确区分；选中状态同时使用表面和边界表达。键盘 focus 清晰可见并绘制在边界内；组合搜索框只由外层显示焦点。disabled 使用专用表面和文字色，保留可辨认文字，不通过整体透明度降低所有内容。状态反馈同时提供文字和语义，不能只依赖颜色。

页面复用工作台按钮和字段组件。图标尺寸由 `WorkbenchIcon` 管理，可滚动的正文使用 `.workbench-scroll-region` 统一滚动条和边距。

配置仓库以状态色条和同色文字标签强化状态；统计物品以选中项内侧强调条标识当前选择，不额外加强已有边框或底色。强调条向容器内绘制，不移动文字或改变列表密度。

## 布局与空间行为

运行模拟、图表预览和配置仓库页面填满可用空间。面板不能为减少留白而改为随内容收缩；内容数量变化时，主要分区应保持稳定。圆形模拟工作流填满控制区的剩余高度。

长内容在所属区域内滚动，滚动所有者必须明确；面板标题保留在内容滚动区域之外，避免用户滚动后失去分区上下文。

Electron 桌面不使用整体 `zoom` 填充大屏。Shell 的 Grid 分配 Sidebar 与 Main，页面通过纵向 Flex 让 Header 按内容占高、Workbench 填满剩余空间。Workbench 使用 `fr` 列比例和 `minmax(0, 1fr)` 行，参与收缩的 Grid/Flex item 显式设置最小尺寸。沿用共享 `border-box`，padding 与 border 均计入容器尺寸。页面不设置大屏最大宽度；Workbench 的字号、控件、图标、间距和侧边栏宽度保持固定，侧栏导航按钮为正方形，宽屏只增加内容空间。统计物品列表在宽屏改为双列，官方配置仓库列表在宽屏改为四列。图表预览按摘要下方可用高度和宽度等比适配；固定结果画布适配由 [Visualization Design](VISUALIZATION_DESIGN.md#结果画布) 维护。

最小窗口为 1280×720，模拟页在这个尺寸下使用双栏。子组件按父容器分配的空间布局，避免用视口高度减去固定值估算剩余高度。布局测试使用 1280×720 和 2560×1440，覆盖 1900px 断点两侧的列数变化。

滚动所有者：

- 运行模拟的物品列表和运行控制正文分别在 `.simulation-item-panel` 和 `.simulation-control-body` 中滚动。模拟插画等比居中，有最小可读高度。窗口较矮时，滚动控制区即可看到状态与操作。
- 图表预览的面板标题与结果摘要固定。静态 CDF 在下方独立滚动区靠左排列，按可用高度等比展示，宽度和原始设计尺寸构成上限。右侧余量留给其他可视化图种。
- 配置仓库：页内切换官方仓库与本地目录，每次只显示一种来源。`.repository-list` 或 `.local-config-list` 在当前来源面板内滚动，分区标题与本地目录保持可见。
- 设置：`.settings-body` 承担外观与软件信息的正文滚动，页头保持可见。
- Main、Page 和 Workbench 不承担普通页面滚动，也不以裁切内容隐藏布局越界。可视化画布由独立宿主适配。

当前配置仓库规格：所选来源的列表面板独占页头、来源切换与概览栏下方的剩余空间。少量内容时仍保留面板高度，长列表在内容区域内滚动。重新进入页面默认显示官方仓库。

## 模拟运行动画

三张直角卡牌从左到右为蓝、紫、金，右侧卡牌压住左侧。入场时三张卡绕共同的底边中点展开。卡面、边框与星芒使用各自的品质色，卡面有同色渐变，金卡内框带一道静态斜向高光。

灰蓝色轨道从卡牌前后穿过，明暗随主题调整。金色正八面体沿轨道公转，同时绕左下至右上的斜轴缓慢自转。自转与公转周期不同，前后两段轨道共享同一姿态。可见面和各面的明暗随朝向变化。

外环表示已完成次数占比，阶段文字区分编译、模拟和保存。次数与百分比使用等宽数字。达到 100% 后仍显示保存状态，直至 GSR 提交成功。

外环头端的小圆跟随进度，中心为中性灰点，周围以面板底色隔开。小圆边缘在待运行时为蓝色，运行与保存时为绿色，保存成功后为金色，取消或失败时为红色。运行动效开启时，小圆的缺口沿顺时针转动，尾迹逐渐淡出。暂停或结束时显示完整实线圆环。

待运行、取消中和终态停止循环动画。切页或隐藏窗口时暂停装饰，返回时按真实进度更新外环，正八面体从暂停姿态继续转动。开启减少动态效果时只展示阶段和进度。

## 交互与状态反馈

点击取消后立即冻结进度、百分比和次数，并显示“正在取消”。终止失败或等待超时时提供“重试取消”，直到进程退出并完成清理。结果文件的提交与取消规则见 [Architecture](../ARCHITECTURE.md#边界与不变量)。

模拟保存成功后，状态行左侧显示“状态 / 已完成”，右侧依次提供“查看本次结果”和“打开结果目录”。两个按钮与状态文字垂直居中，出现时行高保持稳定。点击“查看本次结果”进入结果可视化。载入失败时留在模拟页，显示原因并允许重试。

结果可视化与图表预览共享当前 GSR 会话。未载入时展示工作台的载入引导。读取、取消和失败反馈留在同一面板。

载入后，侧栏提供编辑、图表预览、更换结果、重播动画与导出素材。进入编辑模式后画面显示终态。标题、副标题、模拟目标、统计物品名称、单位和说明在原位编辑，普通字段使用细弱边界，空字段显示占位提示，当前焦点以高对比轮廓标识。单位输入框位于“关键指标”标题右侧，累计值与各项读数同步显示所填单位。展示字段失焦时保存，完成编辑时等待保存成功后退出。失败时保留草稿并提供重试。详见 [DisplayConfig](DISPLAY_CONFIG.md)。

更换结果时，取消或载入失败都会保留当前画面。读取期间禁止重复操作，播放动画时禁用重播。导出对话框关闭后，键盘焦点回到侧栏的触发按钮。

导出流程区分格式选择、覆盖确认、执行进度与终态。部分成功应说明已保存与失败的产物；取消确认后保持阻塞直到任务终态；残留资源清理受阻时保留重试和退出入口，不能通过关闭遮罩或切换页面绕过。模态标题与焦点行为属于交互验收内容。

## 维护与验证

在上述两种尺寸下验证布局契约及现有交互行为，侧栏操作组检查显隐、完整可见、键盘焦点、重播与导出流程。主题验证同时检查内嵌预览、正式可视化和导出画面不受影响。截图按需用于检查层级、密度、明暗衔接、裁切与遮挡，不要求重复采集多个视口或动画帧；主观审美和使用感受由人工判断。不得为让检查通过而放宽无关布局断言。
