# 项目概述
the floder visualize is a project for create viaualize front end page.
the input of this project is the data from simulate,tho output of this project is the image of CDF plot and the vedeo of the draw process.

# 技术栈
主技术栈：
React + TypeScript + Vite
React：前端UI库，负责写页面
TypeScript：编程语言，负责写逻辑并约束数据类型
Vite：前端构建工具，负责启动、开发、打包项目

图表：
Recharts

动画：
Motion + CSS + 少量自定义 SVG 动画

导出：
Playwright 控制 Chromium
截图输出 PNG
录屏输出 WebM
FFmpeg 转 MP4
